# Foodie App Kit

Foodie App Kit is a modern and sleek UI Kit designed to streamline the development of food delivery applications. This template offers an extensive collection of mobile and web screens, delivering intuitive and seamless user experiences. Built with Tamagui, it ensures highly customizable and efficient styling for your project.

## Features

- **Extensive Screen Library:** Includes a variety of screens for mobile and web platforms, such as:
  - Login and Registration
  - Restaurant Listings
  - Food Menu
  - Cart and Checkout
  - Order Tracking
- **Tamagui Styling:** Optimized for performance and flexibility with Tamagui components.
- **Modern Design:** Sleek, user-friendly interfaces tailored for food delivery platforms.
- **Figma File Included:** Easy customization for designers and developers.

## Technologies Used

- React Native
- Tamagui (for styling)
- Figma (for design templates)
- Expo CLI
- Firebase (optional for backend integration)

## Installation

Follow these steps to set up the Foodie App Kit:

1. Clone the repository:
   ```bash
   git clone https://github.com/MHC32/foodie-app-kit.git
   ```

2. Navigate to the project directory:
   ```bash
   cd foodie-app-kit
   ```

3. Install dependencies:
   ```bash
   npm install
   ```

4. Start the application:
   ```bash
   expo start
   ```

## Folder Structure

```
foodie-app-kit/
├── assets/            # Static assets (images, fonts, etc.)
├── components/        # Reusable Tamagui components
├── screens/           # Application screens
├── navigation/        # Navigation setup
├── styles/            # Global styles using Tamagui
├── utils/             # Utility functions
├── App.js             # Main entry point
└── package.json       # Project metadata
```

## Customization with Tamagui

Tamagui allows you to easily customize the styling of your UI components. Modify the `styles/` directory to:

- Adjust theme colors.
- Update spacing, typography, and layout configurations.
- Create reusable design tokens for consistent styling.

Learn more about Tamagui in their [official documentation](https://tamagui.dev/).
